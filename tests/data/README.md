# Test data

- `dvdrental/` (a `pg_restore` directory dump) and `dvdrental_mysql.sql`: the DVD Rental
  sample database, a port of MySQL's [Sakila sample database](https://dev.mysql.com/doc/sakila/en/).
  The Sakila schema and data are licensed under the New BSD license
  ([license](https://dev.mysql.com/doc/sakila/en/sakila-license.html)). The data is fictional
  and is used here only for the demo and the integration tests. Postgres loads the dump with
  `pg_restore` (`tests/docker/pg-init.sh`); MySQL loads the same `.dat` files through
  `dvdrental_mysql.sql` after `tests/docker/mysql-prep.sh` strips their COPY framing.
  `dvdrental_mysql.sql` is generated by `tests/docker/gen_mysql_seed.py`; do not edit it by hand.
- `hostile.sql`: this project's own fixture, shared by the Postgres integration tests (see the
  header comment in the file); some suites (`pg_decode.rs`, `regressions.rs`) add their own
  tables for further edge cases.
